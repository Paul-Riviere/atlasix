# Atlasix

## What is Atlasix ?

Atlasix is a schemas-as-code generator, that helps you create interactive schemas to include in your websites. This doesn't require any library because this works with native svg, so it's light and use browser native rendering.

See live examples on the [demo page](demo/index.md).

## How to use it ?

Add Atlasix files to your HTML file, add your schema's configuration, call the js method, and that's it. See [usage](usage.md) page. Also, see [configuration](configuration.md) page for all configuration options.
