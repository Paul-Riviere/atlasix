# Configuration

Atlasix configuration is made entirely through a single JSON object. Here you'll find a detailed and exhaustive list of available parameters.

## Viewer

### `backgroundColor`

**Description :**

Background color of the entire viewer. Accepted values are css valid color values : 

- *"<css color name\>"*
- *"rgb(x y z)"*
- *"#<hex value\>"*.

**Default value** : "white"
